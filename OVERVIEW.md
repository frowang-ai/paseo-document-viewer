Document viewer opens local HTML and PDF files in separate Paseo workspace tabs beside agents and terminals. The existing file tree, Documents sidebar button and file chooser open files in these tabs. Opening the same file again focuses its existing tab. Each file keeps its page, zoom and scroll position when you switch tabs, close and reopen a file or reload the app.

HTML previews include local styles, images, fonts and classic scripts from the document folder. LaTeX is rendered locally into SVG. The toolbar provides 50–300% zoom and a reset button without reloading the page. Relative PDF links preserve their page anchors. PDF previews provide continuous vertical scrolling, page navigation, zoom, fit width, selectable text, search and password entry. The page number follows the reading position, fit width accommodates the widest page, and only nearby pages are rendered to limit memory use.

This modified checkout supports Paseo 0.11.2–0.12.x on both the daemon and the client, including a 0.11.x daemon with a 0.12.x client. The daemon host needs Node.js 22.22 or later and npm. Connected clients load the viewer from that host and receive document contents through their existing Paseo connection. Setup downloads pinned dependencies and prepares PDF resources, without downloading a browser or opening another HTTP port. Controls are available in English and Korean. Previews run on desktop and web; native mobile clients show an availability notice.

The plugin reads selected files in the current workspace. HTML assets are restricted to the document folder after resolving symlinks. Documents use an isolated iframe with external requests blocked; inline scripts run, and browser policy cannot completely prevent frame self-navigation. The client saves up to 128 recent document paths and reading positions, scoped by host and workspace. Document contents and PDF passwords are not stored there or sent to third-party services. PDF files are limited to 64 MiB. Remote CDN content, API-dependent pages and ES modules are not supported.

Paseo 0.11 and 0.12 have no public file-preview replacement API, so the existing file-tree connection uses their shared DOM structure. The independent file chooser remains available if the app's tree layout changes.
