# Paseo 문서 뷰어

Paseo 안에서 HTML과 PDF를 읽는 커뮤니티 플러그인입니다. 파일 목록에서 문서를 누르거나 사이드바의 **문서** 버튼으로 열 수 있습니다.

파일마다 에이전트·터미널과 같은 줄에 별도 탭이 열립니다. 같은 파일을 다시 누르면 기존 탭으로 돌아갑니다. 페이지·배율·스크롤 위치는 문서별로 기억하며 탭을 닫았다 다시 열거나 앱을 새로고침해도 복원합니다.

## 설치

데몬 컴퓨터에 Paseo 0.11.2–0.11.x, Node.js 22.22 이상과 npm이 필요합니다.

```sh
paseo plugin add git:no-carve-only-pizza/paseo-document-viewer --ref v0.3.0
```

## 보기

- HTML의 **− / 배율 / +**로 50–300%까지 확대·축소합니다. 배율을 누르면 100%로 돌아갑니다. 문서에 포커스가 있을 때 Ctrl/Cmd와 +, −, 0도 사용할 수 있습니다. 배율 변경은 문서를 다시 불러오지 않습니다.
- 문서 폴더 안의 CSS·이미지·폰트·일반 스크립트를 자동으로 포함합니다. LaTeX 수식은 SVG로 렌더링합니다. 상대경로 PDF 링크와 페이지 번호도 연결합니다.
- PDF는 페이지 이동, 확대·축소, 너비 맞춤, 텍스트 선택과 검색을 제공합니다. 암호는 저장하지 않습니다.
- 파일 선택 버튼으로 다른 파일을 고르고, 새로고침으로 원본을 다시 읽습니다. 브라우저·시스템 언어에 따라 한국어 또는 영어로 표시합니다.

파일 선택으로 연 문서도 새 탭에 표시합니다. 탭 배치와 닫기는 Paseo가 관리하고, 플러그인은 최근 문서 최대 128개의 경로와 읽던 위치를 현재 클라이언트의 브라우저 저장소에 기억합니다. 문서 내용이나 PDF 암호는 저장하지 않습니다.

데스크톱·웹용입니다. 원본 파일을 수정하지 않으며 별도 서버나 Chromium을 설치할 필요가 없습니다. 외부 CDN·API·ES module 웹 앱은 지원하지 않고, HTML 자산은 문서 폴더 안으로 제한합니다. PDF 크기 제한은 64 MiB입니다.

기존 파일 목록 연결은 Paseo 0.11용 DOM 어댑터입니다. 앱 구조가 바뀌면 호환성 확인이 필요하며, 별도 문서 패널에서도 파일을 선택할 수 있습니다. 자세한 경계와 개발 명령은 [영문 안내](README.md)를 참조하세요.
